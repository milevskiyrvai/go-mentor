# old_desing — архив неонового дизайна (v1)

Это сохранённая копия исходного фронтенда Go Mentor в **неоновом тёмном стиле**
(chartreuse #D4FF3D + hot pink #FF3D9A, JetBrains Mono, hex-бейджи, glow).

С этим дизайном проект занял **2-е место** на хакатоне itrostik.
Дизайн оценили высоко; минусом была частичная неработоспособность функционала.

Здесь — только исходники (без node_modules/dist):
- `frontend-app/`   — Student/Buddy SPA
- `frontend-admin/` — Admin SPA

**Актуальная разработка** ведётся в новом дизайне «мягкий шалфей» (светлая тёплая тема)
в основных папках `frontend-app/` и `frontend-admin/` проекта.
Макеты шалфея: `design-output/`.
