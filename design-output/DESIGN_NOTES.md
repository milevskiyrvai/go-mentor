## 1. Что произошло и почему (история решений)

- **Был** дизайн «Go Mentor Design System v2» — тёмная тема, неоновые лайм/розовый акценты, «Cyber-RPG, не детское», DARK ONLY. Файлы старого стиля лежат в проекте (`Go Mentor Design System*.html`, `Student · *`, `Buddy · *`, `Go Mentor · 12 screens handoff.html`).
- **Проблема (со слов заказчика):** слишком тёмный, яркие неоновые линии — «не для учёбы, а для сломания мозга». Утомляет глаза при долгом обучении, эмоция «гейм/крипто», а не «доверие/образование».
- **Решение:** новое направление **«тёплая бумага»** — светлая кремовая база, чернильный текст (не чёрный), спокойные природные акценты. Геймификация приглушена.
- Показывали 2 варианта (A — терракота/мягкий; B — шалфей/редакционный). **Заказчик выбрал B.**
- Доп. правки к B: **зелёный смягчён** (был хвойный `#4E6E51` → `#5F8268`), **оранжевость убрана** из крупных блоков (баннер «следующий шаг» переведён в зелёный; терракота — только точечный акцент действия).
- Заказчик попросил также **тёмную версию B** (спокойный тёплый графит, БЕЗ неона) — сделана как `.v-b-dark`.
- A удалён из сравнения. **Финал: вариант B, светлый + тёмный.**

## 2. ВЫБРАННАЯ дизайн-система (вариант B)

Шрифт: **Hanken Grotesk** (400–800), нейтральный чистый гротеск. Числа — табличные (`.num`, tabular-nums).
Лейблы — UPPERCASE с трекингом (редакционный характер). Радиусы малые/чёткие (r 9 / 6 / 4 px). Тени минимальные.
Плотность — сбалансированная.

### Палитра — B светлая (`.v-b`)
- bg `#F5F1E8`, surface `#FFFDF8`, surface-2 `#FFFFFF`
- ink `#221D17`, ink-2 `#5E564A`, ink-3 `#948B7B`
- line `#E5DCCD`, line-2 `#D4C9B5`
- **primary (шалфей)** `#5F8268`, primary-ink `#456450`, primary-soft `#E1EADC`
- **secondary (терракота, ТОЛЬКО акцент действия)** `#B26B45`, secondary-soft `#EEDDD0`
- success = primary; warning `#A9842F`/soft `#ECE0C4`; danger `#AF5840`/soft `#EDD9D0`

### Палитра — B тёмная (`.v-b-dark`, ставится вместе с `.v-b`)
- bg `#1A1D19` (тёплый графит), surface `#232722`, surface-2 `#2A2F29`
- ink `#ECE7DB` (кремовый), ink-2 `#A7A492`, ink-3 `#787667`
- line `#343A32`, line-2 `#454C42`
- primary `#8FB897` (светлый шалфей), primary-ink `#BBD8BF`, primary-soft `#2B3A2E`
- secondary `#D08C66`, secondary-soft `#3A2D25`
- БЕЗ glow/неона. Тени тёмные мягкие.

### Принципы (важно соблюдать на новых экранах)
1. **Светлая/тёплая база, спокойствие.** Никакого неона, glow, чёрного фона (тёмная тема = тёплый графит, не чёрный).
2. **Акцентный цвет ведёт к действию.** Шалфей — основной/статусы; терракота — только «следующий шаг», ключевая кнопка, награда. Не заливать терракотой крупные плоскости.
3. **Геймификация приглушена.** Достижения = мягкие круглые **медальоны-печати** (`.seal`, пунктирное кольцо), НЕ неоновые гексагоны. Бонусы/проценты — спокойные пилюли и бары.
4. Иерархия через типографику и тонкие линейки, а не через цвет/свечение.

## 3. Техническая структура файлов

```
styles/base.css          ← ЕДИНЫЕ стили. Содержит .v-a (устар.), .v-b (свет), .v-b-dark (тёмн.)
                            + всю систему компонентов (sidebar, card, btn, pill, bar, stat,
                            rail, block, mat (материалы), seal/ach (достижения), feed, nextstep, toast).
screens/dashboard.html   ← Student · Дашборд «Мой прогресс»screens/roadmap.html     ← Student · Roadmap (список блоков + детальный блок с материалами-эмбедами)
screens/achievements.html← Student · Достижения (коллекция медальонов + locked с прогрессом)
screens/bonuses.html     ← Student · Бонусы (баланс-счётчик, конвертация в скидку со шкалой 15%, история операций, заявки 1×1)
Go Mentor · Редизайн.html← КАНВАС сравнения (design_canvas.jsx), показывает B свет + B тёмн.
design-canvas.jsx        ← starter-компонент канваса (не трогать)
```

### Переключение темы (механика)
Каждый экран читает `?v=` из URL:
- `?v=b`  → `class="v-b"` (светлая)
- `?v=bd` → `class="v-b v-b-dark"` (тёмная)
- `?v=a`  → `class="v-a"` (устаревший вариант, не использовать)

Канвас встраивает экраны как `<iframe src="screens/NAME.html?v=b">` / `?v=bd`.

### Как добавить НОВЫЙ экран (рецепт)
1. Скопировать готовый экран (напр. `screens/dashboard.html`) как шаблон — там уже sidebar + скрипт темы + подключение `../styles/base.css` и шрифта.
2. Сверстать контент из существующих компонентов base.css. Если нужен новый компонент — добавить в base.css по тем же токенам (var(--…)), НЕ хардкодить цвета.
3. Добавить экран в массив `screens` внутри `Go Mentor · Редизайн.html` (id + label) — появится автоматически в свете и тьме.
4. Размер артборда 1280×860.
